Local services and resource use


Controls are local-only. This page monitors the Mr Smith process and controls Ollama; stop or restart Mr Smith from its PowerShell window with Ctrl+C. Ollama started elsewhere is shown but never stopped by this page. Graceful stop waits for any active model request, unloads models, then asks the Ollama process started here to shut down. Force is used only if graceful shutdown times out.

Import PDF text
