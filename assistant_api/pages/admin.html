Local services and resource use


Controls are local-only. The task list shows Mr Smith and Ollama process IDs and resource use. Ollama started outside this panel is monitored but never stopped here; this panel only gracefully stops the Ollama process it started. Mr Smith itself is launched by your PowerShell/app host, so stop or restart it there rather than terminating a PID from the browser.

Import PDF text


Text-layer PDFs only; maximum 25 MB, 500 pages and 1 MB extracted text. Scanned-image OCR is not supported. Each non-empty page is stored with its page number in the source citation.
